03 / INDEPENDENT PROJECT

Combinational Logic Circuit Design: Date of Birth

Designed and built a three-input combinational logic circuit that displays a date of birth on a seven-segment display. Used truth tables and Karnaugh maps to create the segment logic.

Digital Electronics Combinational Logic Karnaugh Maps Multisim Seven-Segment Displays Hardware Prototyping
04 / INDEPENDENT PROJECT

Synchronous Counters: Medium-Scale Integration (MSI) 74LS193 Up/Down Counter

Designed and built synchronous 4-bit up/down counters, configured custom count ranges in CDS Design and PLD modes, then verified the output with logic probes and display signals.

Digital Electronics Synchronous Counters 74LS193 MSI Logic Circuit Simulation PLTW S7

Copier Jam Detector

Built a three-sensor copier jam detector using digital logic to stop a motor and latch an LED warning. Simulated the circuit in CDS and prototyped it on the PLTW S7.
